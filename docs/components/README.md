# Components

Props tables are generated from the TypeScript types (`npm run docs`) and checked in CI (`npm run docs:check`). Components that wrap a native element also accept that element's attributes, as noted per page. Screenshots come from the repository's gallery page (`site/`) with fictional content and are regenerated by `npm run screenshots`.

| Group | Components |
| --- | --- |
| [Actions](actions.md) | `Button`, `IconButton`, `Spinner` |
| [Form fields](form-fields.md) | `Input`, `Textarea`, `Select`, `Checkbox`, `Switch` |
| [Navigation](navigation.md) | `Tabs`, `SegmentedControl`, `Menu` |
| [Overlays](overlays.md) | `Dialog`, `Sheet`, `Tooltip`, `ToastRegion` |
| [Feedback and surfaces](feedback-and-surfaces.md) | `Badge`, `Card`, `EmptyState`, `StatusIndicator` |
| [Icons](icons.md) | `Icon`, `ICON_NAMES` |

Every group is covered by a behaviour test and an axe-core test in `test/components.test.tsx`; colour contrast is tested separately in `test/contrast.test.ts` ([ADR 0004](../adr/0004-axe-check-per-component.md)).
